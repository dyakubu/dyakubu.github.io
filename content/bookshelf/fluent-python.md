Python's simplicity lets you become productive quickly, but this often means you aren't using everything it has to offer. This hands-on guide by Luciano Ramalho shows how to write effective, idiomatic Python by leveraging its best, and possibly most neglected, features: data structures, functions as objects, object-oriented idioms, control flow, and metaprogramming.
