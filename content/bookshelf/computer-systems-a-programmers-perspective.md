Written by Randal E. Bryant and David R. O'Hallaron, this book explains the enduring concepts underlying all computer systems from the programmer's point of view. It covers data representation, machine-level code, processor architecture, the memory hierarchy, linking, exceptional control flow, virtual memory, system-level I/O, networking, and concurrency, showing how each one affects the correctness, performance, and utility of application programs.
